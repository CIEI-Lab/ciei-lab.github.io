# CIEI Lab 网站第十版

网站包含首页、科研、项目、产品、成员、资源、招聘七个栏目，采用静态 HTML、CSS 与 JavaScript，无需安装依赖。

## 本地查看与转发

在本目录运行 `python -m http.server 8765`，访问 `http://localhost:8765`。也可以在完整解压后直接打开 index.html。

对外审阅可发送 `CIEI-Lab-设计预览-第十版.html`，保存后用普通浏览器直接打开。七个页面、双语、图片、动效和筛选均内置；论文原文、代码仓库等外部链接需要联网。单文件由源码生成，后续请编辑源码并重新打包。

发布目标：`CIEI-Lab/ciei-lab.github.io`。在 GitHub 仓库 Settings → Pages 中使用 GitHub Actions 后，推送 main 分支将触发 `.github/workflows/pages.yml`，预期网址为 https://ciei-lab.github.io/ 。实际发布状态以 GitHub 的部署结果为准。

## 视觉与信息层级

首页、内页开场与产品展区采用后置媒体图层，单独放大、模糊、压暗并叠黑色渐变；前景文字、科研图和照片保持清晰。黑白用于导航、主要阅读区域、深色开场与页脚；研究方向、原创认知场、产品示意和关键词保留局部蓝、青、紫、铜色。教师照片保持原始彩色。首页首屏保留紧凑尺寸，正文导语保持足够对比度。

首页以实验室名称和简介开场，采用研究方向、四篇代表论文、模型与工具、实验平台及交流联系方式的学术结构；各区块使用独立主题插图与暗色蒙层，前景科研图与照片保持清晰原色；科研页保留完整研究说明和重点论文布局。首页不重复完整分类清单或论文动态；科研页的三篇重点论文使用独立的2026年近期研究选择。成员核心块为彩照、一段简介、邮箱及学术链接，不展开履历长表。

## 内容维护

- `assets/content.js`：中文内容；`assets/content-en.js`：英文内容。两份条目的稳定 ID、类别键、顺序对应。
- `assets/i18n.js`：固定界面翻译与语言状态。右上角切换保留页面位置。
- `assets/app.js`：页面结构、筛选、搜索与分批加载。
- `assets/styles.css`：基础布局；最后加载的 `assets/theme.css`：统一视觉、主题色、紧凑首屏与新增内容布局。旧 monochrome.css 已移除。
- `assets/cognition-field.js`：原创 Canvas 认知场。`experience.js`、`tactile.js`、`motion.js`：主题联动、指针与触碰、系统动态偏好和弹窗。
- `assets/exhibit-media.js`：实验平台切换、演示与放大。
- `SOURCES.md`：出处与素材说明。新成果的 `source`、`verification` 字段保留核录证据，不展示成营销说明。

`publications` 使用“论文、著作、专利、软著”作为稳定类型键。原语言出版题名保留原文，英文界面翻译类别和说明，不臆造官方英文书名。`projects` 的类别为“科研项目、企业委托、开源项目”；`group` 分别为 research、industry、open。`openings` 与 `join` 维护参与路径与申请方式。

修改脚本或 CSS 后，需同步更新各 index.html 中的资源版本值；重新生成单文件及源码包，避免审阅副本与源码不同步。

本轮检查 JavaScript 语法、CSS 解析、中英七页内容、真实分类、搜索、筛选重置、分批加载、图示索引、彩色原图保留、离线资源、缓存版本及源码包完整性。本轮已在Codex内置浏览器检查桌面、980px平板和390px手机；中英文内页无横向溢出，图片加载正常。已检查手机菜单、产品详情与禁用操作、摘要展开、双语切换和资源分类。截图保存在outputs/review-v9。


## 第十版维护字段

`presentation.homePapers`指定首页四方向论文；`presentation.researchPapers`独立指定科研页三篇近期论文；`presentation.homeProducts`指定首页产品预览。不要再共用一个featured标记控制两处展示。

产品的`codeAvailable`与`descriptionAvailable`控制操作可用性；`repository`只在有公开实现时使用，`repoURL`可单独保留介绍资料入口。GradChat和PUA没有公开完整实现，代码按钮禁用；FrXXX介绍与代码均禁用。`visualKey`决定原生图示，`tone`决定局部配色。

原摘要使用`abstractOriginal`；来源、版本、语言与许可在对应abstract字段。仅当许可允许时整段展示，CC BY-NC-ND条目保持原文且仅用于非商业展示。无原摘要的条目只提供外部摘要入口。论文内容变动后需同步中英文数据；原摘要不自动翻译。


第十版修复近期研究侧卡：媒体容器与正文显式分区，外链旁挂图标不会再挤占正文网格。原生 SVG 背景位于 assets/art/themes；插图用于主题表达，不是实验设备实拍、论文原图或研究数据。


发布包保留全部网页、样式、脚本与展示素材；论文阅读入口指向期刊或开放仓库，本地归档 PDF 不包含在发布目录中。
